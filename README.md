# EventHub – Event Management Website 🎉

EventHub is a responsive front-end event management website designed to make event planning, promotion, and management simple and user-friendly.

The website includes pages for exploring features, viewing upcoming events, adding custom events, and contacting the event management team.

## ✨ Features

* 🏠 Home page with hero section, highlights, and testimonials
* 📅 Upcoming events listing
* ➕ Add custom events dynamically
* 💾 Store user-created events using LocalStorage
* 🔍 Interactive event detail popups
* 📩 Contact form with validation and success messages
* 📱 Responsive design
* 🧭 Navigation between different pages

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layouts, animations, and responsive design
* **JavaScript** – Interactivity, popups, form handling, and LocalStorage
* **Font Awesome** – Icons
